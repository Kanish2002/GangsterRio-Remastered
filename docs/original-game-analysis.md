# Original Java ME game analysis

**Unverified baseline.** Target: Gameloft *Gangstar Rio: City of Saints* 2011-era 2D Java ME version, **not** the unrelated 3D iOS/Android release. No lawfully usable original JAR/JAD was provided for inspection, so no class decompilation, resources inventory, mission mapping, or gameplay claims can yet be made.

## Procedure once a permitted original is obtained

1. Record source/permissions, file SHA-256, JAR manifest, and JAD metadata.
2. Run it in the pinned browser emulator and independent Java ME reference environment; record screen size, phone type, settings, gameplay and defects.
3. Inventory class names, tile images, sprite atlases, audio formats, RMS records and proprietary blobs without publishing them.
4. Trace input mapping, simulation timing, game states, camera, collisions, vehicles, missions, police responses and save data.
5. Establish repeatable gameplay inputs and comparison evidence before changing presentation.

Do not assume completeness or equivalence across device variants. No downloadable proprietary game copy is linked or redistributed here.
